## One real research pass

1. **Resolve scope and the current checkpoint.** Read the selected program's
   current rules, authorized assets/accounts and testing limits. Retrieve its
   actual native controller and prior evidence. The Social Deal and KOMOJU
   entries in [source pointers](../connector-bridge/source-pointers.v9.json)
   are candidates whose current canonical status must be resolved. Preserve
   existing PASS identifiers and completed questions.
2. **Choose one unresolved security question.** State the expected property,
   the source observations supporting the hypothesis, and what would disprove
   it. Preserve competing legitimate explanations and missing inputs.
3. **Construct typed atoms from evidence.** Retain native subject identity,
   source owner, object ID and ID type, source version, values, dependencies
   and falsifier. Mark assumptions and synthetic alternatives explicitly.
4. **Route through the existing Atlas.** The V13 reasoning planner accounts
   for all 239 candidates. When used, the separate V8 dual-variation router
   accounts for four forward/backward, internal/external-source consideration
   slots per candidate and atom. Those 956 slots are review accounting.
   Select a ready primary and
   a proposed challenger only when each has its required source/input gates,
   explicit adapter, supported native schema and executable control.
5. **Run the next supported bounded calculation.** The host asks the existing
   controller for `next`, calls the registered tool with its returned arguments,
   and admits the actual response receipt. Check negative controls and
   falsifiers. Reuse an exact previous calculation with its original receipt;
   changed source, method, model or declared relationship dependencies reopen
   only affected work. A model counterexample remains a model result.
6. **Verify actual target behavior only when separately authorized.** Use the
   program's permitted assets, accounts and limits for the smallest necessary
   reproduction. Preserve the real request/response evidence, expected versus
   actual behavior, repeatability and demonstrated impact. No target action is
   implied by method selection, model success or this development guide.
7. **Save the bounded result and exact next action.** Retain the original PASS
   format, source versions, tested code commit, hypotheses/falsifiers, actual
   results, remaining dependencies, and checkpoint write/readback identity at
   an authorized destination. Draft a report when actual evidence supports it.
   Submission and any reward remain separate from this engineering validation.

For example, an ownership question might be: can a workflow admit an object
whose owner differs from the authenticated subject? A finite supplied graph
can expose a transition that violates that invariant. A program rule may allow
shared access, or the graph may omit a real authorization check. Those are
falsifiers or alternative explanations to investigate. Actual authorized
observations must establish whether the suspected transition exists in the
target before calling it a finding. This example identifies no target defect.

## Adding a method through GitHub

Use the existing [method contribution workflow](CHATGPT-MPC-OPERATIVE-CONTROLLERS-V13.md#adding-methods-through-github-and-ordinary-chat)
from ordinary ChatGPT, or edit the versioned research definitions through a
GitHub development branch. Supply the primary source, unique typed method ID,
paired classifier, required inputs, falsifier and explicitly proposed
relationships. Validate schema, taxonomy, relation endpoints and source
references, then test the changed source before using the new version.

A catalog definition can be considered immediately by source that has loaded
that tested revision. Computation additionally requires an explicit supported
native adaptation with complete source-bound inputs and controls. A new native
solver needs implementation, registration, tests and a separately authorized
Site deployment. Existing native method IDs and prior results remain intact.
An independent Codex task is optional when this ChatGPT host already provides
the needed execution and GitHub tools.
